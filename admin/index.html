Queue Guidelines

  • When a user initiates a payment task, the system checks this queue first.
  • If a matching payout exists, the user will see that peer's phone number and the number will lock for 60 seconds.
  • When the peer's payment is approved, the queue owner gets marked refunded automatically.
  • If the queue is empty, the system falls back to showing your global admin receiver numbers.
